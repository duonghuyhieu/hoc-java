# Java 100 ngày — code theo video

Code của từng video trong series «Java 100 ngày» trên kênh Hiếu học mỗi ngày. Mỗi ngày một thư mục: README ghi bạn học gì, từng đoạn code trên video kèm lệnh chạy và kết quả máy đã chạy thật, câu đố, đáp án câu đố hôm trước và bài tập.

Cập nhật code mới: `git pull`.

## Cài đặt

JDK 25 (adoptium.net hoặc jdk.java.net). Chạy thẳng file, không cần biên dịch riêng:

```bash
java ngay-001/Buoc1.java
```

Windows mà chữ có dấu hiện thành `?`: chạy `chcp 65001` một lần trong cửa sổ đó, hoặc `java -Dstdout.encoding=UTF-8 ngay-001/Buoc1.java`.
